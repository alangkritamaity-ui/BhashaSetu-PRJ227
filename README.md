# BhashaSetu-PRJ227

## AI-Powered English to Indian Regional Language Translation System

### Project Description

BhashaSetu is an AI-powered translation system designed to translate
English educational and resource materials into Indian regional languages.

The system aims to reduce language barriers and improve access to
educational content for users who are more comfortable with regional languages.

### Objectives

- Translate English text into Indian regional languages
- Support educational and resource materials
- Support PDF and DOCX document translation
- Preserve important technical terminology
- Provide a simple and user-friendly interface
- Maintain translation history
- Provide an optional Learn Mode for simplified explanations

### Proposed Technologies

- Python
- Flask
- HTML, CSS and JavaScript
- IndicTrans2 / multilingual transformer model
- PyMuPDF
- python-docx
- SQLite
- GitHub

### Project Workflow

English Text / Document
        ↓
Text Extraction
        ↓
AI Translation
        ↓
Terminology Processing
        ↓
Indian Regional Language Output
        ↓
Read / Copy / Download
